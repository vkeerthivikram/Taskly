- `taskly-concept.png`: generated concept from the image generation tool. Guides the neutral-and-teal composition; it is not a runtime screenshot.
- `taskly-desktop.png`: actual Chrome file-open runtime, synthetic example tasks, light theme, 1586 × 992 viewport.
- `taskly-mobile.png`: actual Chrome file-open runtime, synthetic example tasks, light theme, 360 × 800 viewport.
- `taskly-dark.png`: actual Chrome file-open runtime, synthetic example tasks, dark theme, 1440 × 960 viewport.
- `taskly-wireframes.excalidraw`: editable Excalidraw scene containing desktop board, task editor, and mobile wireframes. Import this file into Excalidraw to edit it.

Runtime captures were inspected after saving. The app contains no image dependency. Local files were captured on 2026-10-09.
